# AI Video Interview Coach

A resume- and job-specific AI-powered mock video interview platform for students and fresh graduates. The system produces structured feedback along three measurable dimensions: **content**, **voice delivery**, and **body language**.

## Project Status

This repository is at the **D1 planning stage**. It contains the FYDP proposal, product backlog, definition of done, and high-level architecture. No application code is implemented yet.
